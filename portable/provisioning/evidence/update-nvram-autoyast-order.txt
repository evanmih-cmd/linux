Snapshot20260930 AutoYaST systemd-boot update_nvram audit
Date: 2026-10-02

Question:
Is it necessary to remove the stock:
  self.update_nvram = true
from Bootloader::SystemdBoot#propose in addition to importing
<update_nvram>false</update_nvram>?

Exact package:
  yast2-bootloader-5.0.42-1.1

Result: NO. The additional hunk is unnecessary.

Exact AutoYaST import sequence in Bootloader.Import:

1. AutoyastConverter.import creates/imports the profile configuration.
2. import_systemd_boot reads data.global.update_nvram.
3. For profile value "false":
     imported_configuration.update_nvram = false
4. Bootloader.Import clears the factory cache.
5. A fresh proposed systemd-boot configuration is created.
6. proposed_configuration.propose runs.
   Stock propose sets update_nvram = true.
7. proposed_configuration.merge(imported_configuration) runs.
8. SystemdBoot#merge contains:
     self.update_nvram = other.update_nvram unless other.update_nvram.nil?
   Therefore final imported/proposed value becomes false.
9. Bootloader.Import assigns this configuration as current and sets:
     Yast::Bootloader.proposed_cfg_changed = true

Subsequent proposal behavior:

proposal_client reset_needed? can return true on storage change, but calls
Yast::Bootloader.Reset. Bootloader.Reset begins:
  return if Mode.autoinst
so AutoYaST does not clear/re-propose the imported configuration.

The proposal client then sees:
  Yast::Bootloader.proposed_cfg_changed == true
and explicitly does not call bl.propose again.

Therefore no later stock propose overwrites the imported false value in the
normal AutoYaST installation path.

Decision:
- keep the existing minimal AutoyastConverter import correction;
- keep the portable-install call:
    Bls.install_bootloader(portable: update_nvram == false)
- do NOT remove stock SystemdBoot#propose's update_nvram=true default;
- reject the local portable-v2 hunk/artifact as unnecessary implementation
  expansion.

Relevant cached exact-source locations used for the audit:
- lib/bootloader/autoyast_converter.rb
- modules/Bootloader.rb
- lib/bootloader/systemdboot.rb
- lib/bootloader/proposal_client.rb

Product First:
preserve the stock proposal default; override it only through the supported
AutoYaST profile import path.

Economy First:
do not own an extra version-specific source delta that does not change the
required AutoYaST outcome.
