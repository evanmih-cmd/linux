Artifact verification:
- SOURCE-IDENTITY.txt records the official ISO identity, pinned RPM paths,
  pinned stock source hashes and all patch hashes;
- SHA256SUMS covers every regular file in the generated layer except itself;
- SYMLINKS records the complete symlink inventory;
- after ISO creation the builder extracts the ISO again and verifies both
  manifests before publishing the artifact;
- current-build.txt records the external ISO SHA-256.

- Each autonomous VM run writes COM1 directly to runs/<run-id>/serial.log.
- AutoYaST streams complete YaST y2log into COM1 from its pre-script.
